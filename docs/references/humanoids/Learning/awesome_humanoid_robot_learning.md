# Awesome Humanoid Robot Learning - Summary

Awesome Humanoid Robot Learning is a curated paper list for humanoid robot learning.

It collects academic papers and related resources, mainly organized by the task each paper focuses on.

## Reference Value

| Point | Why it matters |
| --- | --- |
| Curated humanoid learning papers | Useful starting point for finding important research |
| Task-based categories | Makes it easier to search by locomotion, manipulation, navigation, or sim-to-real |
| Real robot experiments preferred | Helps focus on work that has been tested beyond simulation |
| Open-source code highlighted | Useful for finding papers with reproducible implementations |
| Covers hardware and simulation | Good bridge between robot design, training, and evaluation |

## Why It Is a Good Reference

- Shows the main research directions in humanoid robot learning.
- Useful for tracking recent papers and project websites.
- Helps compare learning methods by task area.
- Good benchmark for what topics a serious humanoid learning study should cover.

## Repo Note

Awesome Humanoid Robot Learning is a strong reference because it is a maintained research index, not a single project or isolated paper.

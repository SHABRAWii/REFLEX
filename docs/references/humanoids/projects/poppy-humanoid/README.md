# Poppy Humanoid - Summary

Poppy Humanoid is an open-source, 3D-printed humanoid robot from the Poppy Project.

It is optimized for research and education, with a modular body, Robotis Dynamixel actuators, printable mechanical parts, software tools, hardware files, and documentation.

## Reference Value

| Point | Why it matters |
| --- | --- |
| Open-source humanoid platform | Useful example of a public research and education humanoid |
| 3D-printed mechanical structure | Good reference for printable body-part design and modular hardware |
| 25 Dynamixel actuators | Useful for studying a lightweight full-body actuator layout |
| Hardware and software releases | Helps compare CAD, STL, STEP, software, and install workflow organization |
| Raspberry Pi 3/4 control support | Practical example of embedded Linux control for Dynamixel-based robots |
| CoppeliaSim simulation support | Useful reference for simulation-backed experimentation and teaching |

## Why It Is a Good Reference

- Shows a lightweight humanoid architecture focused on education, research, and hackability.
- Useful for comparing printable mechanical design against heavier metal-frame humanoids.
- Good reference for Dynamixel-based actuation, embedded control, and modular robot documentation.
- Helps evaluate the tradeoff between accessible fabrication and high-performance biped hardware.

## Repo Note

Poppy Humanoid is a strong reference because it combines open hardware, open software, educational documentation, and a long-running community project in one public platform.

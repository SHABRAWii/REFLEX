# Asimov v0 - Summary

Asimov v0 is an open-source bipedal leg project for humanoid robots.

It provides a complete humanoid leg design using off-the-shelf components and low-volume manufacturing methods.

## Reference Value

| Point | Why it matters |
| --- | --- |
| Open-source bipedal leg design | Useful reference for humanoid lower-body architecture |
| 12 DOF actuation | Good example of joint distribution across two legs |
| 6 DOF per leg | Helps compare hip, knee, ankle, and toe design choices |
| Articulated toe | Useful for studying foot contact and gait mechanics |
| RSU ankle mechanism | Interesting mechanical approach for ankle mobility |
| Mechanical and simulation files | Helpful for studying both physical design and model-based testing |

## Why It Is a Good Reference

- Shows a focused humanoid leg design instead of a full-body system.
- Useful for comparing DOF, joint limits, torque needs, and actuator placement.
- Good reference for manufacturable mechanical design.
- Helps separate lower-body design decisions from full humanoid complexity.

## Repo Note

Asimov v0 is a strong reference for humanoid leg mechanics because it focuses on real hardware constraints, not only simulation or research theory.
